# Core Acceptance Evidence

Generated by `python -m scripts.run_acceptance`: **33 of 33 checks passed.** Each scenario ran on the real network (separate processes, UDP on 127.0.0.1); its folder holds every device's log (`<device>.jsonl`), the exact topology (`config.json`) and the commands and seeds (`run.json`). Deterministic fault tests (forced drop, link failure, loop) are kept separate from the random-loss run, which has its own recorded seed.
